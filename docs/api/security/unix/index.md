# security.unix

The `security.unix` module exposes Unix security types.

## Types

| Type                        | Description                       |
| --------------------------- | --------------------------------- |
| [`Acl`](./acl.md)           | POSIX.1e access-control list      |
| [`Ace`](./ace.md)           | POSIX.1e access-control entry     |
| [`Identity`](./identity.md) | Unix process identity information |
