# Errno

[`sys.unix.Errno`](../unix/errno.md) originating from macOS.

## Constructor

### `Errno value`

Creates a macOS error number.

#### Parameters

| Name  | Type                      | Description      |
| ----- | ------------------------- | ---------------- |
| value | [`int`](../../std/int.md) | Raw error number |

Known codes are available as class fields such as `Errno.ENOENT`.
