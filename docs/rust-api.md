# Rust API

Rust crates for embedding Do and integrating it with other Rust software.

!!! warning "Unstable APIs"
    These Rust APIs have no stability guarantees. Breaking changes may occur
    at any time. Rust API compatibility will stabilize, if ever, substantially
    later than the Do language and Do-level APIs.

| Crate                                            | Description                                        |
| ------------------------------------------------ | -------------------------------------------------- |
| [`dolang`](../rustdoc/dolang/)                   | Embeddable public API for the Do language          |
| [`dolang-rpc`](../rustdoc/dolang_rpc/)           | Asynchronous RPC with native handle passing        |
| [`dolang-vfs`](../rustdoc/dolang_vfs/)           | Virtual filesystem library and extension interface |
| [`dolang-winterop`](../rustdoc/dolang_winterop/) | Portable Windows interoperability primitives       |
